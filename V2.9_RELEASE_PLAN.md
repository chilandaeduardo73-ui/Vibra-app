# VIBRA v2.9 — Release Candidate

## Estado
Os testes estruturais locais passaram na v2.8. Esta versão acrescenta uma verificação de pré-lançamento para evitar iniciar produção sem configuração mínima.

## Antes do deploy
Definir no servidor:
- `NODE_ENV=production`
- `DATABASE_URL`
- `SESSION_SECRET` com pelo menos 32 caracteres
- `DATABASE_SSL=true` quando exigido pelo provedor

Executar:
```bash
npm install
npm run check
npm run smoke
npm run preflight
npm start
```

Depois validar:
- `/api/health`
- `/api/db-status` deve indicar `postgres`
- duas contas e interações entre elas
- persistência após reinício

## Importante
O pacote não cria contas de hospedagem, banco de dados ou domínio. Essas etapas dependem de serviços externos e autorização do proprietário.
