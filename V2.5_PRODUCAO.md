# VIBRA v2.5 — Correção de persistência e preparação de produção

## O que foi corrigido
- Criada uma camada `db.js`.
- Quando `DATABASE_URL` existe e o PostgreSQL está acessível, o VIBRA usa PostgreSQL.
- Em desenvolvimento local, existe fallback para `data.json`.
- Adicionada rota `/api/db-status` para verificar o modo de persistência.
- Adicionado `pg` às dependências.
- Criado `.env.example`.

## Importante
O fallback local é intencional para desenvolvimento. Antes do lançamento público, configure `DATABASE_URL` e confirme que `/api/db-status` retorna `postgres`.
