# VIBRA v2.6 — Correção e testes

## Correção
Foi consolidada a camada de persistência para evitar inicialização duplicada do banco. O PostgreSQL é usado quando `DATABASE_URL` está configurado; o modo local fica reservado ao desenvolvimento.

## Smoke test
Execute:

```bash
npm install
npm run check
npm run smoke
```

## Teste de produção
Depois, com PostgreSQL real:

1. Definir `DATABASE_URL`.
2. Iniciar com `npm start`.
3. Consultar `/api/db-status`.
4. Confirmar `mode: postgres`.
5. Criar duas contas.
6. Testar publicação, comentários, seguidores e mensagens.
7. Reiniciar o processo.
8. Confirmar que os dados continuam disponíveis.

O smoke test local não substitui o teste multiutilizador em servidor real.
